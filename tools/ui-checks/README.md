# UI checks (headless browser)

Scripts that drive the real app in headless Microsoft Edge (puppeteer-core), print PASS/FAIL checks and save screenshots. Not part of CI; run them by hand after UI changes.

Setup (once): `npm install` in this folder. The scripts use Edge at `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`; change `executablePath` if your browser is elsewhere (Chrome works too).

Run the app first: API on :5000 (`npm --prefix server start`), UI on :5173 (`npm --prefix client run dev`). For a throwaway demo database, set `POS_DB_PATH` and `POS_UPLOADS_PATH` to a temp folder before starting the server.

| Script | Purpose | Usage |
|---|---|---|
| `seed-demo.mjs` | Seeds a demo café ("Ganesh Bhavan": 5 categories, 16 items, staff priya/manager123, ravi/cashier123 with PIN 1234 and meena/cashier123, a few bills and one void) through the API, so all validation applies. Run on a fresh DB; it signs in with the seeded admin/admin123. | `node seed-demo.mjs` |
| `upload-demo-photos.mjs` | Uploads item photos from a folder (file name = item name). | `node upload-demo-photos.mjs <photo dir>` |
| `take-screens.mjs` | Screenshots of every screen. Nav labels may need updating (written before the icon rail). | `node take-screens.mjs <out dir>` |
| `e2e-phase2.mjs` | Fresh install → setup wizard → owner login; or demo shop → all Settings sections. | `node e2e-phase2.mjs fresh\|demo <out dir>` |
| `settings-move.mjs` | Rail items, Staff/Audit log inside Settings, Staff table fit and "⋯" menu, Manager view. | `node settings-move.mjs <out dir>` |
| `billing-after.mjs`, `billing-detail.mjs`, `restore-check.mjs`, `shell-after.mjs` | Billing fits 1366×768, photo tiles, rail, switch user, dialogs. | `node <script> <out dir>` |
| `proto-check.mjs` | Checks the counter-concept prototype. | `node proto-check.mjs <html file> <out dir>` |

The prototype `docs/prototypes/counter-concept.html` is generated by `docs/prototypes/source/build.mjs` from `template.html` (`node build.mjs <client dir> <photos dir> <out file>`).
